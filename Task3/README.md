2. Базовые инструменты защиты

2.1. Медицинские данные 

Инструменты защиты:

- Шифрование на диске (AES-256)
- Шифрование при передаче (TLS 1.3)
- Маскирование в интерфейсах
- Обезличивание для аналитики

2.2. Персональные данные (ПДн)

Инструменты защиты:

- Шифрование на диске (AES-256).
- Шифрование при передаче (TLS 1.3)
- Токенизация для внешних интеграций
- Маскирование в API и логах
- Автоматическое удаление по запросу

2.3. Платёжные данные

Инструменты защиты:

- Шифрование полей с номерами карт при хранении (AES-256)
- Токенизация — хранение только токенов вместо реальных номеров карт
- TLS 1.3 при передаче между платёжным шлюзом и банком

2.4. Ключи шифрования

Инструменты защиты:
- Хранение в защищённом хранилище
- Ротация ключей
- Аудит доступа к ключам.
- Разделение ключей

3. Автоматизированный контроль

|Инструмент|Назначение|
